Predicting Recidivism using Deep LearningPredict recidivism using a deep learning model trained on 48,000+ records from NIJ, COMPAS, and North Carolina. This project implements end-to-end data processing and advanced feature engineering in TensorFlow/Keras, reaching a stable 68-69% accuracy.  Engineered FeaturesThe pipeline processes the recidivism_merged_dataset.csv file and engineers several domain-specific variables:  Severity & Volume: The Criminal_Severity_Score weighs violent and felony arrests, while Arrest_Rate and Felony_Density measure crime frequency relative to age.  Socioeconomic Factors: The Instability_Index combines unemployment and substance abuse into a single instability score.  Demographics & History: The dataset includes an Is_Young_Offender flag and tracks the Sentence_per_Arrest.  Model ArchitectureThe binary classification model is built as a Keras Sequential network:  Data Scaling: The input features are normalized prior to training using StandardScaler.  Hidden Layers: The network contains two Dense layers with 64 and 32 units, utilizing ReLU activation and HeNormal weight initialization.  Regularization: Standard Dropout layers set at a 0.2 rate follow each hidden layer to prevent overfitting.  Output & Compilation: The model ends with a single-unit Sigmoid output layer compiled with the Adam optimizer using a 0.0001 learning rate and binary crossentropy loss.  Training & PerformanceTraining Protocol: The model utilizes an 80/20 train-test split alongside an EarlyStopping callback with a patience of 50 epochs to restore the best weights.  Dataset Balance: The target variable for recidivism has a natural distribution of roughly 52.6% for class 0 and 47.3% for class 1.  Results: The final evaluation yields precision, recall, and F1-scores of approximately 0.68 across 9,630 test samples, supporting an overall accuracy of 68-69%.
